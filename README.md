# Sistema de RH

Projeto do sistema de processos de recrutamento e seleção.

## Estrutura

- `frontend/` — aplicação React/Vite.
- `docs/` — especificações, pesquisas, referências visuais, relatórios e QA.
- `tools/` — scripts de apoio.

### Frontend

O código da interface está em `frontend/`. Para instalar as dependências e iniciar o ambiente local, execute os comandos a partir dessa pasta.

### Documentação

- `docs/reports/` — relatórios de alinhamento.
- `docs/quality/` — registros de garantia de qualidade visual.
- `docs/visuals/` — mockups e imagens comparativas.
